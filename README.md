# Zomato Live Data Analysis

## Project Overview
This project focuses on analyzing "real-time Zomato restaurant data" to gain insights into restaurant performance, 
customer preferences, pricing patterns, and ratings. The analysis helps understand food trends,
popular cuisines, and factors affecting customer ratings using data analytics and visualization techniques.

---

## Objectives
- Analyze restaurant data collected from Zomato  
- Understand customer preferences based on ratings and votes  
- Identify popular cuisines and restaurant types  
- Analyze pricing trends and availability of online delivery  
- Perform exploratory data analysis (EDA) with visual insights  

---

## Dataset Information
- Dataset Type: Real-time / Live scraped Zomato data  
- Key Features Include:
  - Restaurant name  
  - Location / City  
  - Cuisine types  
  - Average cost for two  
  - Rating  
  - Votes  
  - Online delivery availability  
  - Table booking availability  

---

## Tools & Technologies Used
- Programming Language:Python  
- Libraries: 
  - Pandas  
  - NumPy  
  - Matplotlib  
  - Seaborn  
- Environment: Jupyter Notebook / VS Code  

---

## Analysis Performed
- Data loading and cleaning  
- Handling missing and inconsistent values  
- Exploratory Data Analysis (EDA)  
- Restaurant rating analysis  
- Cost vs rating analysis  
- Cuisine popularity analysis  
- Online delivery and table booking analysis  
- Location-based restaurant trends  
- Visualization using bar charts, box plots, and distribution plots  

---

## Visualizations Included
- Distribution of restaurant ratings  
- Top cuisines based on restaurant count  
- Average cost comparison by cuisine  
- Rating vs cost analysis  
- Online delivery vs customer ratings  
- Location-wise restaurant distribution  
- Votes vs ratings relationship  

---

## Key Insights
- Restaurants offering online delivery tend to receive higher engagement  
- Certain cuisines are more popular and receive better ratings  
- Higher cost does not always guarantee higher ratings  
- Customer votes strongly influence restaurant visibility  
- Location plays a significant role in restaurant popularity
